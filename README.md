# Reportería Prestadores Webapp

Frontend React + TypeScript + Vite conectado a la API real de Render.

## StackBlitz
1. Crear un proyecto React TypeScript.
2. Reemplazar los archivos por los incluidos.
3. Crear `.env` copiando `.env.example`.
4. Ejecutar `npm install` y `npm run dev`.

## Backend
`VITE_API_URL=https://reporteria-api.onrender.com`
